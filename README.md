# E-Commerce Stock Control System

##  Description

A simple **MySQL-based Stock Control System** designed to manage products, categories, sellers, and inventory.

##  Technologies Used

* MySQL
* SQL

##  Database Tables

* **Category** – Stores product categories.
* **Product** – Stores product name, price, and category.
* **Seller** – Stores seller details.
* **Inventory** – Stores product quantity and reorder level.

##  Features

* Create and manage database tables
* Add product and seller details
* Manage inventory
* Perform CRUD operations
* Check available products
* Find out-of-stock products
* Find highest stocked product
* Calculate average stock
* Check products below reorder level
* Analyze inventory using SQL JOINs

The SQL file includes the database creation, sample records, CRUD operations, and inventory analysis queries.
